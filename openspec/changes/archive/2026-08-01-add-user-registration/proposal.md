## なぜ必要か

現在のアプリケーションでは、ユーザーがシステムを通じてアカウントを作成する方法がありません。これにより、オンボーディングができず、今後の認証系機能の実装も始められません。ユーザー登録機能を追加することで、アカウント作成の入口を明確にしつつ、既存機能の挙動を維持したまま新しい登録フローを導入できます。

## 何を変更するか

- ユーザー登録機能を追加し、アプリケーション経由で新しいユーザーアカウントを作成できるようにします。
- ユーザーを永続化するための基本的なユーザー表現と識別子を導入します。
- 既存のアプリケーション境界を通じて登録処理を提供し、現行の API 体験からも利用できるようにします。

## 変更対象

### 新規機能
- ユーザー登録: アプリケーション経由で新しいユーザーアカウントを作成する動作を追加します。

### 変更対象の機能
- なし。

## 影響範囲

- 影響範囲: アプリケーションサービス、永続化層、アカウント作成に関わる API / コントローラー処理。
- 影響依存関係: ユーザー情報を保存するためのリポジトリおよび永続化設定。
- 影響動作: 関連しない既存フローは変更せず、新しい登録フローが利用可能になります。
