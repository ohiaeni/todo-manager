# task-management-api Specification

## Purpose
この機能により、ユーザーは自分に紐づくタスクを安全に登録・更新・削除でき、他ユーザーのタスクへは操作できない API 契約を提供する。

## Requirements

### Requirement: ユーザーは自分のタスクを登録できる
システムは、認証済みユーザーから有効なタスク登録要求を受け取った場合、当該ユーザーに紐づく新規タスクを MUST 作成する。

#### Scenario: タスク登録に成功する
- 認証済みユーザーが必須項目を満たしたタスク登録リクエストを送信した場合
- システムは当該ユーザーに紐づくタスクを作成し、成功レスポンスを返すこと

### Requirement: ユーザーは自分のタスクを更新できる
システムは、認証済みユーザーが自身に紐づく既存タスクを更新要求した場合、指定フィールドを MUST 更新する。

#### Scenario: タスク更新に成功する
- 認証済みユーザーが自身に紐づくタスク ID と有効な更新内容を送信した場合
- システムは対象タスクを更新し、更新後の内容を含む成功レスポンスを返すこと

### Requirement: ユーザーは自分のタスクを削除できる
システムは、認証済みユーザーが自身に紐づく既存タスクを削除要求した場合、対象タスクを MUST 削除する。

#### Scenario: タスク削除に成功する
- 認証済みユーザーが自身に紐づくタスク ID の削除リクエストを送信した場合
- システムは対象タスクを削除し、成功レスポンスを返すこと

### Requirement: 他ユーザーのタスクは操作できない
システムは、認証済みユーザーが他ユーザーに紐づくタスク ID を登録・更新・削除対象として指定した場合、要求を MUST 拒否する。

#### Scenario: 他ユーザーのタスク更新を拒否する
- 認証済みユーザーが他ユーザー所有タスクの更新リクエストを送信した場合
- システムは権限エラーとして要求を拒否し、対象タスクを変更しないこと
